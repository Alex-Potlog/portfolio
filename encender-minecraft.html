Un servidor de Minecraft que se enciende cuando lo necesitas.

Una pequeña plataforma para iniciar mundos de juego bajo demanda. El proyecto combina infraestructura cloud y una interfaz sencilla para que el servidor no tenga que estar encendido todo el tiempo.

Ver página del proyecto ↗ Ver código en GitHub ↗

¿Qué hace?

La página permite elegir entre los mundos Mods e Invierno y solicitar su encendido. Tras enviar la contraseña, consulta el estado de la instancia y muestra la dirección del servidor cuando está listo para jugar.

La interfaz está pensada para ser directa: explica cada mundo, ofrece una acción principal clara y comunica el progreso mientras el servidor arranca.

Arquitectura y tecnologías

La web estática se comunica con una API de AWS para gestionar las acciones del servidor. La infraestructura usa EC2 dentro de una VPC; las funciones Lambda y API Gateway coordinan las solicitudes, con IAM para los permisos.
